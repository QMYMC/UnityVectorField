# 公开准备说明

本地发布候选由 `PUBLISH_FILES.txt` 逐文件列出；包含 Unity 必需目录、资源 `.meta`、公开合成示例、测试、工具和说明。`Tools/prepare_public.py` 可生成无 Git 历史的本地候选副本和文件哈希；不会自动暂存、提交或上传。

## 已处理

- 默认场景和数据全部由解析公式生成；原始数据、旧场景和旧设计记录保存于忽略目录 `LocalOnly`，不进入候选。
- 未迁入业务消息、实体管理、内部事件中心、沙盘组件、私有 DLL、业务色带或原项目资源目录。
- 保留现有用户材质修改、Unity 版本和包配置；旧 UI、相机及地理数学辅助代码保留为独立示例/适配。核心不依赖它们。
- 发布候选的源码、序列化资源和配置进行模式扫描；图片只允许本次运行生成的 PNG。日志、缓存、构建、备份和审计原始结果不发布。
- 所有者已确认候选文件的公开范围，并选择 MIT；根目录 LICENSE 覆盖本仓库自有代码与示例。保留第三方版权声明；包自带许可仍按对应包处理。

## 发布边界

1. 仅发布清单内的通用代码、资源和合成数据；不迁入原型旧 Git 历史、stash、原始数据或本地保留文件。
2. 目标为所有者账号下的新仓库 `QMYMC/UnityVectorField`，采用独立的初始提交。原型历史保持原样。
3. Unity 包依赖仍遵循各自许可证；项目 MIT 许可不能替代它们。
4. 后续加入数据、图片或第三方代码时，应重新检查来源、授权与敏感内容。

## 本地复查

```text
python Tools/prepare_public.py --meta --audit-history --output CleanValidation/Review
```

工具使用 Python 标准库；扫描当前候选与所有 Git 引用中的 blob，输出只留在 `LocalOnly/Audit`。模式扫描不是完整密钥审计，不检测所有编码、隐写或高熵秘密；历史提交者信息和资源授权仍需人工确认。导出不会复制 `.git`、Library、原始数据或本机日志。
